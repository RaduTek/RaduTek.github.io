This is my personal website. Designed using CSS3 and HTML5 to early 2010s levels, except `backdrop-filter` which requires a modern browser.

### Browser compatibility

- Internet Explorer 7-11
- Safari 3 and newer (tested on iOS 3, 4, 5 and 6)
- Firefox 4 and newer
- Chrome probably, idk

Theme switching via the footer link works on IE8 and newer, requires browser support for `localStorage` API to persist across refreshes.
